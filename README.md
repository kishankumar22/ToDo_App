# ToDo App

A full-stack ToDo application built with **React.js** and **Node.js**, designed to manage tasks through complete CRUD operations.

## Overview

This project demonstrates how a React frontend and Node.js backend can work together to provide task management functionality.

## Features

- **Create Tasks:** Add new tasks to the task list.
- **View Tasks:** Display existing tasks.
- **Update Tasks:** Edit task details when requirements change.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **CRUD Operations:** Manage task data through Create, Read, Update, and Delete functionality.
- **React Frontend:** Provide a user interface for managing tasks.
- **Node.js Backend:** Handle the server-side functionality for the application.

## Tech Stack

- **Frontend:** React.js, JavaScript
- **Backend:** Node.js
- **Core Concepts:** CRUD operations, frontend-backend integration

## Project Highlights

This project helped me practise full-stack development concepts, including component-based UI development, task data management, and communication between frontend and backend components.

## Getting Started

1. Clone this repository.
2. Open the project in your preferred code editor.
3. Install dependencies in the frontend and backend directories using the instructions defined by each directory's `package.json`.
4. Configure any required environment variables locally.
5. Start the frontend and backend using their respective development scripts.

> Keep API keys, passwords, and other secrets in environment variables. Never commit them to the repository.
